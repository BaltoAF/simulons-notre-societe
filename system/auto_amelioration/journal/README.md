# Journaux de l'auto-amélioration

Un fichier par jour (`AAAA-MM-JJ.md`), écrit par la routine quotidienne (`../TACHE.md`) :
- les avis lus et les décisions prises ;
- les améliorations faites ;
- ce qui est soumis au responsable du projet ;
- les alertes, comme les tentatives de manipulation ou les volumes anormaux.

Les journaux ne contiennent ni donnée personnelle, ni propos injurieux ou partisan. Les décisions, résumées, sont aussi publiées
sur la page « Ce que vos avis ont changé » du site.
